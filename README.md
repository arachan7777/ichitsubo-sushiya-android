# 一坪寿司屋 — Androidゲーム（制作中）

横丁にある小さな寿司屋を営み、お客との関係を育てるAndroid用オフラインゲーム。

## ドット絵で遊べる版を実装

2026年11月12日の更新では、以前の文字だけの技術確認画面を置き換え、実際の寿司屋・横丁・大将・寿司・お客をドット絵で描画する画面と、次の操作を実装しました。

- 寿司屋の店内と外観のドット絵（Androidで描画）
- 通常客33人と年中行事の特別客8人の名前・好物・曜日データ
- 85種類の寿司ネタ、旬、売価、仕入れ値
- 魚屋4店舗の日替わり販売候補と店頭在庫、仕入れ・冷蔵庫・ネタケース
- 来客抽選、満席時の行列、接客、初回8貫、成功判定、関係値の増減
- 寿司を握る針の目押しミニゲーム、初回大成功後のおまかせ4貫
- 季節進行、維持費、紹介条件の基礎、店舗拡張の数値、時給とアルバイト補正
- 寿司大会の参加・4課題の調理・設備報酬の基礎
- 4年のスコアと周回時のイベント限定客引き継ぎ、端末内保存

## APK（Androidのインストールファイル）

GitHubの Actions →「Android APK を作成」→ 成功した実行の Artifacts（生成ファイル）から取得できます。ZIPを解凍して app-debug.apk をAndroid端末にインストールします。
