# 一坪寿司屋 — Androidアプリ（開発中）

Android向けの寿司屋育成・交流ゲーム「一坪寿司屋」の初期開発用ソースです。Replitは使用しません。

現在は基本的な暦・金銭・来客抽選・スコア・周回規則・端末保存の検証画面のみ実装しています。接客、寿司85品目、登場人物41人の交流、仕入れ、物語などの主要機能は未実装です。完成版ではありません。

Android SDK 35 / Java 17 / Gradle 8.7 / Android Gradle Plugin 8.6.1 を使用します。

GitHub Actions の「Android APK を作成」は手動実行です。ビルド成功時のみ、生成されたデバッグAPKをダウンロードできます。初回ビルド成功と実機動作は未確認です。

本体完成後に任意のリワード広告と広告なし課金を接続する予定です。現段階で広告配信や課金は組み込みません。

原典にない仕様を勝手に追加せず、暫定値はテスト後に検証します。
